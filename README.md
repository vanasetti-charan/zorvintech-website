Official website project for **Zorvintech Private Limited**, an India-focused technology and business services company specializing in technology solutions, digital accessibility, AI, web and mobile development, cloud solutions, IT consulting, and business services.

## 🚀 Deployment

This website is hosted using **GitHub Pages**.

### Deploy with GitHub Pages

1. Create a GitHub repository.
2. Upload the website files.
3. Make sure `index.html` is in the repository root.
4. Upload the `images` folder containing the Zorvintech logo.
5. Go to:

```text
Repository → Settings → Pages
```
